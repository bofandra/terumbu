# Departure fields: managed defaults and no invented operational values

- New departure form uses the **saved expedition meeting point** (when available) as an editable initial suggestion.
- Trip leader input can reuse saved partner team names, but does not assign anyone automatically. Selecting a person does not attest that they are available to lead that date.
- Seat capacity and minimum group size do not have fixed example values that might be mistaken for confirmed operational facts.
- When minimum group size is unspecified, admin display keeps it unspecified; it is not silently shown as six participants.
- Existing departure edits preserve persisted fields. No payment or lifecycle changes, and publication readiness remains enforced by the backend.
